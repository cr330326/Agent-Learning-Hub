# 采用自托管 Next.js 与单节点 SQLite

首版采用自托管 Next.js 应用和部署服务器本地 SQLite，以满足 GitHub 登录、跨设备学习状态和本地 Docker 共用镜像的需求，同时保持单服务器运维简单。该选择明确接受单写节点和不可水平扩展的限制；当并发写入或多实例部署成为真实需求时，再将用户状态迁移到 PostgreSQL。

## Consequences

- 云端只能运行一个写入 SQLite 的应用实例。
- SQLite 数据文件必须放在本机持久化磁盘，不能放在网络文件系统。
- 必须配置一致性备份、异地保留和恢复演练。
- 课程正文仍由 Git 管理，不进入 SQLite。
