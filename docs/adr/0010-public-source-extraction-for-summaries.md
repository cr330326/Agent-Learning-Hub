# 允许后台读取公开来源生成资讯摘要

飞书或其他采集信源可能只提供标题和链接。为使资讯摘要具有实际内容依据，允许云端后台尝试读取公开原文或可获取的视频字幕，再生成中文摘要与推荐理由。站内展示摘要和出处，全文与视频通过原站链接访问；读取失败时展示已有信息，并标注摘要缺失。

此决定调整 [ADR 0002](./0002-third-party-materials-are-references.md) 中云端禁止抓取第三方正文的约定，将公开来源的后台摘要处理纳入范围。本地素材库的云端交付边界仍按 ADR 0002 执行。

访谈也考虑过仅使用飞书、RSS 等信源已提供的内容。用户选择补充读取公开来源，以改善仅有标题和链接时的摘要依据，并接受相应的采集耗时与失败处理成本。

生成摘要后，后台读取的原文与字幕保留 7 天，用于重试和复核，到期清理；摘要、来源链接和处理记录继续保存。待处理或失败副本自抓取起最多保留 7 天，到期后按需要重新获取并记录新版本。原文与字幕存放在独立临时卷，持久化备份保存摘要、引用和处理记录；恢复时执行到期检查。

决定依据见 [设计讨论 Q4、Q6、Q13](../plans/cloud-content-design.md)。Q16 已确认数据生命周期，正式要求见 [规格 §20](../plans/spec.md#20-云端资讯与学习扩展)，实施状态见 [任务 Phase 9](../plans/tasks.md#phase-9-云端资讯与学习衔接)。
