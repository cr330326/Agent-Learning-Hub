# 资讯按信源发布，学习目录由维护者确认收录

云端提供资讯与学习双入口。资讯按采集信源配置发布方式，认可的来源完成去重、主题筛选和字段校验后自动发布，新来源先人工确认。系统可以推荐适合长期学习的资讯、所属阶段和收录理由，加入公共课程目录与九阶段路线须由维护者确认。

这一决定支持资讯的日常自动更新，同时由维护者控制公共学习路线的质量与资料数量。访谈考虑过系统按规则自动收录、再由维护者调整或撤回的方式，用户选择在收录前确认，并接受维护者处理推荐条目的工作量。

后台将推荐资料、所属阶段与收录理由整理为 GitHub PR，由维护者审阅合并，再通过版本发布流程上线。后台展示对应 PR、合并与上线状态，便于追踪收录进度。

本决定依据 [设计讨论 Q1、Q3、Q5、Q11](../plans/cloud-content-design.md)，延续 [ADR 0006](./0006-catalog-is-hand-maintained.md) 的人工策展边界。资讯存储见 ADR 0011，后台正文处理见 ADR 0010；Q16 已确认整体方案，正式要求见 [规格 §20](../plans/spec.md#20-云端资讯与学习扩展)，实施状态见 [任务 Phase 9](../plans/tasks.md#phase-9-云端资讯与学习衔接)。
