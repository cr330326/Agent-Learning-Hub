# 第三方素材只作为来源引用，不进入云端内容包

云端只发布 Curated Content，并通过导览页链接到 Upstream Source；`local-courses/` 被定义为本地素材库，不随云端镜像发布，也不由服务器抓取或代理第三方正文。这个选择牺牲了云端站内阅读全部资料的便利性，以换取清晰的版权边界、更小的部署体积和始终指向上游最新版的访问方式。

## Consequences

- 第三方 Learning Item 必须记录作者、来源和许可证状态。
- Local Mode 可以只读访问白名单内的 Local Material。
- 许可证明确且确有必要的内容，必须经过单独审核后才能进入 Curated Content。
