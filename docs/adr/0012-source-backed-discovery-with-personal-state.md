# 本机云端试运行取消资讯内容落库并保留个人状态库

用户为本机 Docker 中的 Cloud Mode 试运行选择从指定飞书多维表格和 openspace 读取标题、已有摘要与原始链接，以短时内存缓存支持展示，取消资讯内容落库。登录身份、收藏、私人笔记和学习进度继续由学习状态数据库保存。

这一决定调整 [ADR 0011](./0011-single-host-with-separate-discovery-store.md) 中本次试运行的资讯内容持久化边界，满足用户简化服务端内容存储的目标。历史日报、上游变化后的个人引用、信源配置与缓存失效行为在[补充访谈](../plans/cloud-content-design.md#只读信源试运行补充访谈进行中)中继续确认，整体方案确认后同步正式规格和实施任务。

## 用户澄清后撤回

2026-11-15，用户进一步说明，现有定时任务每天向飞书和 GitHub 同步数据，飞书作为主要数据来源，网站承担信息聚合、原始链接跳转与聚合学习，并要求随上游更新。用户请 Agent 设计合理的数据库结构，此前“取消资讯内容落库”的记录未准确表达这一意图，现撤回该存储限制。后续方案见 [ADR 0013 提案](./0013-feishu-led-aggregation-with-persistent-read-model.md)，两库实现仍以 ADR 0011 为现行基线。
