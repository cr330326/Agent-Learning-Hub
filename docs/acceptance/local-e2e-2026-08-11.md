本轮同时修复了三项验收中发现的实现缺陷：

1. Local 生产 HTTP 会把 CSRF Cookie 标记为 `Secure`，浏览器不会在回环 HTTP 发送它；现按实际请求协议设置 Cookie 属性。
2. 页面遥测在 Next 规范化请求 URL 后误判本机 `127.0.0.1` 同源请求；现以 Host/代理协议重建同源 Origin，仍拒绝跨域请求。
3. 删号成功后空态分支会卸载成功消息；空态现在保留状态提示。

另修复根 `.gitignore` 的通用 `lib/` 规则，使 `code/lib/` 的运行时源文件不会再被 Git 静默忽略，并添加回归测试。
